# **App Name**: SnapID Pro

## Core Features:

- Hybrid Image Source: Quickly import images from your device gallery or capture new photos directly using an integrated low-latency camera interface.
- Precision Image Editor: Adjust brightness, contrast, and saturation using high-performance filters optimized for low-end device CPUs.
- Global Size Presets: Apply standard passport sizes (2x2 inch, 35x45mm) or define custom width and height parameters in millimeters or inches.
- Legacy Stroke Engine: Apply a Photoshop-style border with customizable pixel width and a color picker to ensure high-contrast ID edges.
- Multi-Image Print Canvas: Drag-and-drop workspace for A4 or 6x4 paper sizes to duplicate, arrange, and align multiple copies for efficient printing.
- AI Auto-Adjustment Tool: A generative AI tool that analyzes photo lighting and background, suggesting optimal color balance and contrast for official ID standards.
- Lossless PDF Export: An offline processing module that merges canvas layouts into high-resolution, print-ready PDF, JPG, or PNG files.

## Style Guidelines:

- Primary color: Sharp Blueprint Blue (#2e54b8), conveying reliability and professional utility.
- Background: Minimalist Frosted White (#f3f5f8), chosen for extreme clarity on varied screen types and low battery consumption.
- Accent: Arctic Cyan (#26b3d9), used sparingly for active states and critical calls-to-action like 'Generate PDF'.
- The 'Inter' sans-serif typeface provides a machined, objective look suitable for a technical utility tool and maintains readability on low-DPI displays.
- Thin-line, geometric vector icons to minimize memory overhead while maintaining a modern, agency-standard aesthetic.
- A rigid grid system with substantial padding between touch targets to ensure accuracy for users with larger hands or smaller mobile screens.
- Hardware-accelerated micro-interactions restricted to essential feedback (like successful image import) to keep the experience snappy on low-RAM devices.
